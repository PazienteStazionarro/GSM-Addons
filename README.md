# GSM - Дополнения
Дополнения можно устанавливать только поверх [GSM](https://github.com/PazienteStazionarro/GSM). Дополнения созданы для кастомизации и замены контента. Они не являются обязательным контентом и не добавляют что-то новое - они только заменяют старое. Дополнения не конфликтуют друг с другом, дополнения одного и того же типа взаимозаменяемы. Установка дополнений аналогична [установке GSM](https://github.com/PazienteStazionarro/GSM?tab=readme-ov-file#%D1%83%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B0).

-----------------------------  

### Список доступных дополнений:
Female VO
>Заменяет стандартную озвучку на женскую. Работает только с национальной озвучкой. Языки, доступные только сменой языка клиента, например украинский и испанский, затронуты не будут.

Legacy Music
>Заменяет музыку на старую, из WoT 0.9.22. Ангарная тема заменяется на аналогичную из 0.9.22, но музыка на вкладках в ангаре остается.

KorbenDallas Settings
>Применяет лучшие настройки громкости отдельных групп звуковой картины для комфортной игры, делая менее важные звуки тише.



### Дополнения в разработке:
WoT 2.0 Contents
>Делает изменения, совершенные в обновлении World of Tanks 2.0. Заменяет звуки интерфейса, музыку в ангаре, улучшает звуки поверхности под гусеницами, столкновений танков, меняет параметры громкости некоторых объектов.

Hangar V2 Basic Music
>Заменяет музыку в ангаре на тему базового ангара V2 (0.9.22).

Hangar V2 Premium Music
>Заменяет музыку в ангаре на тему премиум ангара V2 (0.9.14).

Hangar V2 Premium Random Music
>Заменяет музыку в ангаре на тему премиум ангара V2 (0.9.22).

Hangar V4 Music
>Заменяет музыку в ангаре на тему ангара V4 (2.0).

Hangar h08 Music
>Заменяет музыку в ангаре на тему ангара обновления Мира танков "Альфа" (1.32).

Legacy Chinese VO
>Заменяет китайскую озвучку на старый вариант.
